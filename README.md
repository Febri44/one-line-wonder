# one-line-wonder

One line, at most 200 characters, written to make a reader feel wonder,
written to `/output/entry.txt` by `main.ts` (Node 22). Built for the make.fun bounty
[u-pangg7-one-line-of-wonder-ee10fcd8](https://make.fun/bounty/u-pangg7-one-line-of-wonder-ee10fcd8).

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt`.
